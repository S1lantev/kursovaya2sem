# АС «База детейлинг студии»
Курсовой проект по дисциплине «Командное проектирование и разработка».
Силантьев К.Д., группа ЗПИуд-123.

## Запуск
Консольное приложение C# для .NET Framework 4.8.
Откройте DetailingCourse.sln в Visual Studio либо выполните build.cmd.
Запустите src/DetailingCourse/bin/DetailingCourse.exe.
Управление раскрывающимся меню: стрелки вверх/вниз, Enter, Escape.

## Функции
1. Запись клиентов: календарь, занятость мастера, отмена.
2. Задания: список работ и переходы «Запланировано» → «В работе» → «Завершено».
3. Материалы: остатки в литрах, списание на визит, сигнал пополнения.

Данные сохраняются в JSON; при повторном сохранении создаётся .bak.
В демонстраторе принята смена 10:00–18:00. Права мастера проверяются по введённому имени,
это учебная модель и не заменяет серверную аутентификацию.
Автоматический заказ поставщику в этой версии заменён сигналом потребности в пополнении.
Одновременная работа нескольких процессов, веб-интерфейс, эквайринг, CRM и оффлайн-обмен
не реализованы в демонстраторе и входят в проектный план веб-системы.

## Проверки
После сборки:
src/DetailingCourse/bin/DetailingCourse.exe --self-test evidence/local-check
src/DetailingCourse/bin/DetailingCourse.exe --demo evidence/local-demo

Для --demo нужен новый каталог, чтобы сохранить существующие данные.
Контрольный результат: 31 passed, 0 failed. Журналы находятся в evidence/.

## Ветки
feature/bookings, feature/jobs, feature/materials подготовлены от общей базы
в отдельных локальных каталогах. Модули объединены в final, затем в master.
main — основная опубликованная ветка. Исправления интеграции и документы добавляются
после слияния в master и передаются в main.
